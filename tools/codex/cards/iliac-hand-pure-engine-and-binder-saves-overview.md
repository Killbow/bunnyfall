# Iliac Hand Pure Engine, Binder Saves, and Collections

The Iliac Hand rules engine in `src/net/iliacHand.js` operates as a pure state machine without calling `Math.random`, wall clocks, or cryptographic primitives directly. All deals inject an external random source validated on every draw up to `ILIAC_RAND_DRAWS_MAX` (`100_000`), returning `null` if any draw is invalid. Card effects generated by `fxText` in `src/net/iliacCards.js` pass through `fxRefusal` validation in `src/net/iliacHand.js`, and `CARD_EMBLEMS` in `src/net/iliacCards.js` matches `EMBLEM_KEYS` in `src/render/iliacCardFaces.js`.

## Binder Persistence, Worth, and Collections

Save loading in `src/saves/save.js` runs `cleanBinders` (`src/cards/iliacItems.js`), capping stored decks at `BINDER_DECKS_MAX` (`12`), validating each deck through `validBinderDeck`, and assigning tier-based card worth from `src/net/cardWorthLaw.js`. Quickslot keys in `src/items/quickslots.js` append the card catalog ID, and `rekeyOldBooks` migrates older book slot keys to avoid collisions.

In the Holdings menu (`src/ui/enhancedMenu.js` and `src/ui/familyPages.js`), `setCollectionsPart` routes navigation into `drawCollectionsPage` (`src/ui/collectionsPage.js`), which mounts the binder (`src/ui/cardBinderPage.js`). Any armed deck deletion is cleared by `disarmCollectionsPage` or `disarmFamilyPages` on filter change, tab switch, or page exit.
