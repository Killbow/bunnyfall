# The site's two pixel faces

The website's front page (`landing.css`) is set in the desktop launcher's faces, from the same files: **Jacquard 12**
for headings and **Pixelify Sans** for everything else. These are copies of `app/launcher/fonts/` (see the README there
for where they came from and their checksums). Both are under the SIL Open Font License 1.1 (`OFL-Jacquard12.txt`,
`OFL-PixelifySans.txt`).
